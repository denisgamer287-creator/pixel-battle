# Pixel Battle

У цьому репозиторії знаходиться безкоштовний шаблон сайту типу Pixel Battle.

Що реалізовано:
- Полотно 60x36 пікселів
- Вибір кольору
- Один піксель кожні 15 хвилин
- Таймер з відліком часу
- Збереження даних у localStorage
- Підтримка Supabase для онлайн-синхронізації

Швидкий старт:
1. Відкрийте проект локально через будь-який статичний сервер.
2. Можна просто виконати:
   python -m http.server 8000
3. Потім відкрийте http://localhost:8000

Підключення до Supabase (безкоштовно):
1. Створіть проект на https://supabase.com
2. Відкрийте SQL Editor і виконайте вміст файлу `db/schema.sql`
3. Скопіюйте `config.example.js` в `config.js` або просто змініть значення у `config.js`
4. Вставте URL проекту та anon key
5. Перезавантажте сторінку

Важливо:
- У базовому режимі сайт працює і без Supabase — дані зберігаються локально в браузері.
- Для загального онлайн-доступу обов'язково потрібен Supabase або інший backend.

Публікація:
- GitHub Pages або Cloudflare Pages — підходять для цього статичного проєкту.
- Для GitHub Pages просто опублікуйте репозиторій як статичний сайт.

Файли:
- `index.html` — структура сайту
- `styles.css` — стилізація
- `app.js` — логіка полотна і таймеру
- `config.js` — конфігурація Supabase
- `db/schema.sql` — SQL-скрипт для бази даних
